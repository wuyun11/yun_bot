# 命令与校验

## 本地 Python 解释器文件

在执行编译检查、导入检查或运行项目之前，先检查下面这个文件是否存在：

- `config/python_path.local.txt`

这个文件用于保存当前电脑可用的 `python.exe` 绝对路径。

约定：

- 文件内容只写一行
- 这一行就是 `python.exe` 的绝对路径
- 该文件只用于当前电脑本地环境
- 该文件必须被 `.gitignore` 忽略，不提交到仓库

示例参考：

- `config/python_path.local.example.txt`

## 运行前检查规则

在执行下面这些动作之前，先检查 `config/python_path.local.txt`：

- 编译检查
- 导入检查
- 运行项目
- 运行脚本

如果文件不存在，不要直接猜测解释器路径，应先创建该文件并写入本机可用的 `python.exe` 绝对路径。

## 推荐使用方式

如果 `config/python_path.local.txt` 存在，则优先读取其中的解释器路径，再执行命令。

例如：

```powershell
$python = Get-Content .\config\python_path.local.txt -Encoding UTF8 | Select-Object -First 1
& $python -m compileall .\src .\bot.py
```

## Windows 终端约定

- 尽量显式使用 UTF-8 读取文本
- 搜索文件和文本优先使用 `rg`
- PowerShell 下尽量减少 profile 和编码干扰

## 修改代码后的最小校验

至少做两类检查。

### 1. 编译检查

```powershell
$python = Get-Content .\config\python_path.local.txt -Encoding UTF8 | Select-Object -First 1
& $python -m compileall .\src .\bot.py
```

### 2. 关键导入检查

至少检查本次改动涉及的关键模块能正常导入。

例如：

```powershell
$python = Get-Content .\config\python_path.local.txt -Encoding UTF8 | Select-Object -First 1
& $python -c "from src.langchain_app.infra.config import app_config; print(app_config.refs_dir())"
```
